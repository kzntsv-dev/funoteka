# funoteka mark

The mark is **a disc and its tracks**: a solid record with a label, and the four bars it was cut into.
One accent only — the disc's label `#E4572E`. Ink `#16140F`, paper `#F5F2EC`.

Geometry (viewBox `100`): disc `c(26,50) r=17`; label `r=6.2`; spindle hole `r=2.4` (masked out);
bars at `x=54`, pitch `17`, height `6.2`, lengths `34/34/25/34`.

Below 32px the mark switches to a deliberately simplified drawing — a bigger disc, fewer and
thicker bars. That is not a scaling accident: thin internals disappear at icon sizes, so the
small mark is a different drawing of the same idea.
